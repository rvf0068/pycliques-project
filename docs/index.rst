Pycliques Graph Theory Ecosystem
================================

Welcome to the unified documentation for the Pycliques monorepo. 

Terminology
-----------

In this project, a **complete** is a mutually adjacent set of vertices, and a
**clique** is a maximal complete. This follows the clique-graph literature;
in particular, it differs from the common modern usage in which "clique" may
mean any complete set.
